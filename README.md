SuperMarket_Report – Power BI

Project Overview

This project focuses on analyzing supermarket sales data using Microsoft Power BI to build an interactive dashboard and support data-driven business analysis.

Tools & Technologies

* Microsoft Power BI
* Power Query
* Data Modeling
* DAX (Data Analysis Expressions)

Project Workflow

1. Imported and combined transaction data.
2. Cleaned and transformed data using Power Query.
3. Created relationships and developed the data model.
4. Created calculated columns and DAX measures.
5. Designed an interactive SuperMarket_Report Dashboard.
6. Used visualizations to present sales-related information.
